# Guitar-App
An online store app for displaying and ordering guitar products.

## Features
- [x] Login
- [x] Registration
- [x] Password Reset
- [x] Update profile
- [x] Syncing data when openning a new tab
- [x] Login with Google
- [ ] Login with Facebook
- [ ] Cart
- [ ] Order & Checkout
